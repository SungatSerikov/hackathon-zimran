# Инструменты для художника

Нужен только Node.js (без `npm install`).

## 1. Заглушки спрайтов

```
node tools/make-placeholders.mjs
```

Создаёт в `public/assets/` все PNG из `ASSETS.md` §4 (включая `folder_open`, `coffee_empty`, `safe_open`, `monitor_on` и 8 портретов 48×48). Уже существующие файлы **не перезаписываются** (там может лежать настоящий арт); в конце скрипт печатает, что создано и что пропущено. Флаг `--force` перезаписывает всё, **кроме** рисованных спрайтов и фона (все файлы из следующего раздела): они защищены, `--force` их не трогает (создаются только если файла нет). Чтобы их обновить, запускайте `npm run sprites`.

Настоящий арт: положите PNG с тем же именем и размером в `public/assets/...`.

### Рисованные спрайты и фон (всё нарисовано вручную)

```
node tools/draw-sprites.mjs     # или: npm run sprites
```

Рисует попиксельно и **всегда перезаписывает** (в `public/assets/`):

- `scene/`: `bg.png` (480×270), `clock.png` (36×36), `calendar.png` (44×52), `coffee.png` и `coffee_empty.png` (24×28), `safe.png` и `safe_open.png` (70×60), `phone.png` и `phone_ring.png` (56×40), `cabinet.png` (110×40), `monitor.png` и `monitor_on.png` (150×120), `folder.png` и `folder_open.png` (140×80), `board.png` (150×80), `stamps.png` (110×55);
- `ui/`: `stamp_guilty.png` и `stamp_not_guilty.png` (120×40, единственное место с текстом), `claim_form.png` (200×120);
- а также `src/scene/sprite-meta.json`.

`phone`, `phone_ring`, `cabinet`, `stamp_guilty`, `stamp_not_guilty`, `claim_form` создаются **только** этим скриптом (в `make-placeholders.mjs` для них нет заглушек); остальные из списка выше в `make-placeholders.mjs` есть, но защищены (см. выше). Палитра и PNG-кодировщик общие: `tools/lib/pixel.mjs` (32 цвета, лимит 32; приглушённый чистый офисный стиль, контуры тёмные тонированные, не чёрные). Свет справа-сверху, мягкий. Старые `ui/stamp_approved.png` и `stamp_denied.png` удалены (вердикт теперь GUILTY / NOT GUILTY).

Данные для оверлея в коде (координаты в пикселях спрайта; тот же JSON лежит в `src/scene/sprite-meta.json`):

- Часы: центр оси `cx=17, cy=17`, максимальная длина стрелки `handMax=11` px (стрелок в спрайте нет — рисует код). Ось в пикселе (17,17) — на пол-пикселя левее/выше геометрического центра холста 36×36 (17.5, 17.5): круг диаметром 35 px, последние строка и колонка прозрачны. Так и задумано; рисуйте стрелки от (17,17).
- Календарь: чистая страница (однотонный `#f5f3ee`) `x=4, y=21, w=36, h=22` — сюда код рисует месяц и число.
- Монитор (`monitor` и `monitor_on`): однотонная область экрана `x=26, y=20, w=98, h=52` — сюда код рисует интерфейс поиска; виньетка и блик только за её пределами.
- Папка открытая (`folder_open`): две чистые страницы `{x=11,y=15,w=52,h=54}` (левая) и `{x=77,y=15,w=52,h=54}` (правая).
- Доска (`board`): рабочая пробковая область `x=6, y=6, w=138, h=68` (по углам нарисованы две бумажки и кнопки — карточки можно класть поверх).
- Бланк жалобы (`ui/claim_form`): линии трёх строк (Claimant / Respondent / Request) `rows = [{x=14,y=52,w=172}, {x=14,y=74,w=172}, {x=14,y=96,w=172}]`; над каждой линией есть светлая плашка 34×4 под подпись поля.

```json
{"clock":{"cx":17,"cy":17,"handMax":11},"calendar":{"page":{"x":4,"y":21,"w":36,"h":22}},"monitor":{"screen":{"x":26,"y":20,"w":98,"h":52}},"folder_open":{"pages":[{"x":11,"y":15,"w":52,"h":54},{"x":77,"y":15,"w":52,"h":54}]},"board":{"area":{"x":6,"y":6,"w":138,"h":68}},"claim_form":{"rows":[{"x":14,"y":52,"w":172},{"x":14,"y":74,"w":172},{"x":14,"y":96,"w":172}]}}
```

## 2. Превью сцены

```
node tools/scene-preview/serve.mjs
```

Откройте напечатанный URL (по умолчанию http://127.0.0.1:5174/). Порт меняется через переменную `PORT`: bash — `PORT=5175 node tools/scene-preview/serve.mjs`, PowerShell — `$env:PORT=5175; node tools/scene-preview/serve.mjs`. Остановка: Ctrl+C.

- Перетаскивайте предметы мышью (шаг 1 пиксель базовой сцены); выбранный предмет двигается стрелками, Shift — по 10.
- Справа можно поправить x, y, w, h числами; переключатели состояний показывают `*_open`, `*_empty`, `*_on`, если такие файлы есть.
- «Перечитать» подхватывает обновлённые PNG и layout.json без перезапуска (несохранённые правки раскладки при этом сбрасываются).
- Кнопка в правом верхнем углу сворачивает панель: на окне 1024px сцене тогда хватает места на масштаб ×2.
- Предметы, вышедшие за 480×270, перечисляются предупреждением в панели.
- Нет спрайта — вместо него пунктирный прямоугольник с id.

## 3. Сохранение раскладки

Нажмите «Скачать layout.json» (или «Скопировать JSON») и положите результат в `src/scene/layout.json`. Пути спрайтов — относительно `public/assets/`.
