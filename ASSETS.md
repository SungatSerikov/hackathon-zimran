# ASSETS — визуал и список ассетов

Для человека B. Код читает раскладку из `src/scene/layout.json`, поэтому координаты можно двигать без программиста.

## 1. Направление

- **Пиксель-арт**, вид на рабочий стол сидящего сотрудника бюро жалоб в маленьком американском городке.
- Стиль: чистый современный пиксель-арт, спокойный дневной офисный свет. Приглушённая малонасыщенная палитра: тёплые светло-серые и беж, мягкий уголь, орех для дерева, серебро и белый для техники, приглушённый зелёный акцент (растение, шапка календаря). Свет мягкий, справа-сверху.
- Форма: тени и свет в 2–3 ступени без резкого контраста; **без чисто чёрных контуров** — контур тёмный тонированный (угольный, тёмно-коричневый или на материал темнее), местами можно без контура. Настроение: уютное бюро жалоб в маленьком американском городке, обычный (не нуарный) детектив.
- **Одна палитра на всё**: 24–32 цвета. Возьмите любую бесплатную палитру с lospec.com (поиск по 32 colors) и придерживайтесь её.
- Вдохновляемся жанром (стол с предметами, папка документов, штамп), но **не копируем** чужие игры: не используем их скриншоты как референс для img2img, не повторяем их интерфейс, персонажей и цвета один в один. Нужен свой узнаваемый стиль — это ещё и +10% оригинальности.

## 2. Технические правила

- Базовое разрешение сцены: **480×270** px. Всё рисуется в этом масштабе; код вписывает сцену в окно с сохранением пропорций.
- Формат: **PNG** с прозрачностью, без сглаживания (anti-aliasing выключен), без полупрозрачных краёв.
- Каждый интерактивный предмет — **отдельный спрайт** (чтобы подсвечивать и анимировать).
- Имена файлов — как в таблице ниже, папка `public/assets/`.

### Если останется время (P2)

- Пар над кофе (3–4 кадра), мигание курсора монитора, анимация открытия папки.
- Звуки (CC0 с freesound.org или сгенерировать в jsfxr): штамп, шелест бумаги, клавиатура, «новая улика», ошибка.

## 5. Как быстро получить пиксель-арт

1. Сгенерировать картинку (Midjourney / DALL·E / любой генератор) с промптом вида:
   `pixel art, 32-color muted palette, clean modern look, calm daylight small-town US complaints office desk, CRT monitor, wall clock, tear-off calendar, cork board, small safe, front view, no text, game asset`
2. Уменьшить до целевого размера **без сглаживания** (nearest neighbor).
3. Привести к палитре и подчистить в **Pixelorama** или **Piskel** (бесплатно, в браузере) или Aseprite.
4. Предметы вырезать в отдельные PNG с прозрачностью.

Генераторы плохо держат единый стиль — поэтому шаги 2–3 обязательны, иначе портреты и предметы будут из разных миров.

## 6. Шрифты (Google Fonts, бесплатно)

- Заголовки, кнопки: `Silkscreen` или `Press Start 2P`.
- Текст документов и поисковика: `VT323` или `Pixelify Sans` — длинный текст должен читаться.

## 7. Порядок работы

1. Палитра + `bg.png` + монитор + папка + штампы → отдать в код (к ~3 часу).
2. Портреты учебного дела.
3. Остальное по списку P0 → P1.

## Подключено в рабочей игре

Сцена 480×270 вписывается в окно с сохранением пропорций и `image-rendering: pixelated`. Игра использует исходный `layout.json` (`base.w/h`, `x/y/w/h/z`, `sprite`, `action`). Сейф теперь хранит игровую валюту, телефон выдаёт подсказки, отдельный шкаф открывает будущие премиум-дела. `phone.png` и `cabinet.png` подключены к рабочим действиям; CSS-заглушки остаются на случай отсутствующего файла. После добавления новых имён файлов перезапустите dev-сервер: список доступных ассетов собирается при запуске/сборке. Замена файлов с существующими именами не требует изменений логики.

`npm run scene:preview` — исходный редактор ассетов. `npm run dev` — сама игра. `npm run preview` — проверка production-сборки игры. Не запускайте `npm run placeholders` поверх готовых рисунков.

Текст кнопок вердикта рисуется кодом для читаемости: **GUILTY — красный**, **NOT GUILTY — зелёный**. Новые оттиски `stamp_guilty.png` / `stamp_not_guilty.png` доступны в ассетах. `sprite-meta.json` задаёт центр стрелок часов, область даты календаря и область текста монитора.

### Состояния во время игры

Сцена получает активный предмет из текущего окна: телефон использует `phone_ring.png` при открытом информаторе, папка — `folder_open.png` при чтении дела, компьютер — `monitor_on.png` при поиске, сейф — `safe_open.png` при открытом кошельке. Закрытие окна, включая Escape, возвращает обычный спрайт. Количество денег больше не держит сейф постоянно открытым; баланс доступен в HUD. Пустые кружки по-прежнему зависят от оставшихся попыток. Если файла дополнительного состояния нет, используется основной спрайт.
